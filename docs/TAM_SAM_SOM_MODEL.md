## 1. DASTLABKI TADQIQOT GIPOTEZALARINI QAYTA TIKLASH

Tadqiqot hisobotida keltirilgan bazaviy ko'rsatkichlar:
* **Jami manzilga ega bozor (TAM):** ~$64.8 million / yil
* **Xizmat ko'rsatilishi mumkin bo'lgan bozor (SAM):** ~$18.4 million / yil

### TAM Rekonstruksiyasi ($64.8M / yil):
* **Fermer xo'jaliklari (tijoratbop qismi):** ~60,000 ta subyekt $\times$ o'rtacha $500/yil ($42/oy) = **$30.0M**
* **Qishloq xo'jaligi korxonalari va KO'B lari (Agri-SME):** ~20,000 ta subyekt $\times$ o'rtacha $1,200/yil ($100/oy) = **$24.0M**
* **Eksportyorlar va qayta ishlovchi yirik korxonalar:** ~3,000 ta $\times$ o'rtacha $2,500/yil ($208/oy) = **$7.5M**
* **Agrosanoat klasterlari:** ~600 ta $\times$ o'rtacha $5,500/yil ($458/oy) = **$3.3M**
* **JAMI TAM:** $30.0M + $24.0M + $7.5M + $3.3M = **$64.8 million / yil**

### SAM Rekonstruksiyasi ($18.4M / yil):
O'zbekistonda muntazam ravishda bank krediti oluvchi, elektron faktura (Didox) va 1C dasturlaridan faol foydalanuvchi agrobiznes subyektlari (TAM ning taxminan 28-30% qismi):
* **Faol kredit oluvchi fermerlar:** ~15,000 ta $\times$ $500/yil = **$7.5M**
* **Raqamli buxgalteriyaga ega Agri-SME:** ~6,500 ta $\times$ $1,200/yil = **$7.8M**
* **Meva-sabzavot eksportyorlari:** ~1,000 ta $\times$ $2,000/yil = **$2.0M**
* **Klasterlar (Agrobank bilan ishlovchi):** ~200 ta $\times$ $5,500/yil = **$1.1M**
* **JAMI SAM:** $7.5M + $7.8M + $2.0M + $1.1M = **$18.4 million / yil**
